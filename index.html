[EN]

CREATOR: İsmail Ayas

DESCRIPTION: A GIS simulator developed entirely with a 'from scratch' philosophy, without depending on any pre-built software; a full-fledged technical software aimed at having a modern engineering interface and functionality in every detail—from its SVG-based vector drawing engine to its dynamic snap system—capable of not only visualizing data but also exporting it in industrial formats (DXF).

PROJECT NAME: Netcad Reimagined

TECHNOLOGIES USED: HTML5, CSS3, JavaScript (SVG-based drawing engine).

PROJECT FEATURES:

  • Add Point (+)
  • Polyline
  • Create Polygon
  • Parallel Line Creation
  • Symbol and Icon Library
  • Precise Coordinate Input (X, Y, Z)
  • Endpoint Snapping
  • Midpoint Snapping
  • Intersection Snapping
  • Distance Measurement
  • Area Calculation
  • Volume (Cubage) Calculation
  • Object Querying
  • Layer Management
  • Layer Color and Style Settings
  • Layer Locking and Hiding
  • Layer Search
  • Move
  • Rotate
  • Scale
  • Extend
  • ITRF Transformation and Coordinate Settings
  • DXF Import
  • DXF Export
  • Raster (Image) Loading and Management
  • Mini Map
  • Undo / Redo
  • Point Editor
  • Hatching Styles
  • Dynamic Labels and Information Panels
  • Zoom and Pan (Navigation) Tools
